🖱️ Running the Application

Once the download has finished, running the application is a matter of opening the file you just received. Use the list below as a straightforward checklist.

  1. Press the Windows key on your keyboard and type Downloads, then press Enter. This opens the folder where downloaded files collect.
  2. Find the item you downloaded from the releases page. If several files are listed, the newest date at the top belongs to this download.
  3. Double-click that item to open it. Windows may briefly show a security prompt; this is a normal safety check, and you can confirm to continue.
  4. If a window appears asking whether you want to allow the application to make changes, choose Yes.
  5. Wait a few seconds for the first launch. The very first start can be slower than later ones because Windows is still learning about the new file.
  6. The application window opens and you are ready to use it.

If the file opens in a browser tab instead of as its own window, that is expected behaviour for a web-based project. The content is the same either way.

If something does not go as expected, work through the suggestions below before anything else.
